# KNOWN_ISSUES

## 검증하지 못한 것

- **사람이 플레이해 본 적이 없다.** 재미, 난이도 체감, 설명 이해도는 전혀 검증되지 않았다. 자동 테스트와 봇 시뮬레이션은 "고장 나지 않는다"와 "수치가 폭주하지 않는다"만 보여 준다.
- **소리를 들어 본 사람이 없다.** 효과음·배경음악은 합성한 뒤 수치로만 확인했다. 거슬리거나 어색할 수 있다.
- **Windows에서 실행해 본 적이 없다.** 내보내기(.exe 생성)와, 같은 내용물을 Linux에서 실행하는 것까지만 확인했다.
- 화면 확인은 1920×1080(2배)에서만 캡처로 했다. 1280×720, 울트라와이드, 4K, Steam Deck은 미확인.
- 성능: headless 계산 속도만 쟀다(8년 시뮬레이션 약 2분 반). 실제 그래픽 프레임 속도는 소프트웨어 렌더링 환경이라 측정하지 못했다. 동시 손님은 봇 기준 최대 60~70명 수준까지만 확인.

## 알려진 문제 / 한계

- **후반 콘텐츠 부족**: 봇 기준 5~6년차에 모든 시설이 최고 레벨이 되고 그 뒤로는 돈이 쌓이기만 한다. 등급 7(랜드마크)까지 가는 마지막 구간에 할 일이 적다.
- 주차장을 5레벨까지 올리면 한 칸에 차 두 대가 겹쳐 보여 빽빽하다.
- 차는 주차 칸으로 들어갈 때 앞 칸의 차를 통과한다(주차장 내부 경로 없음).
- 손님끼리 서로 피하지 않고 겹쳐 지나간다. 줄이 길면 입구 앞 방향으로 건물과 상관없이 늘어선다.
- 키 큰 건물 바로 뒤 칸의 손님이 지붕에 가려 보이지 않을 때가 있다. 3×2 건물 모서리에서 깊이 정렬이 드물게 어긋날 수 있다.
- 정원·놀이터처럼 걸어 다니는 시설 안의 키 큰 소품(나무, 미끄럼틀) 앞뒤 관계가 정확하지 않다.
- 불러오기 직후, 걷던 손님은 목적지를 다시 고른다(저장 전과 다른 가게로 갈 수 있음). 돈·통계는 그대로다.
- 계절이 바뀌어도 풍경은 그대로다(통행량과 제철 상품만 반영). 날씨 없음.
- 상품·재료에 그림이 없어 이름으로만 표시된다.
- 연구는 한 번에 하나만. 연구 대기열 없음.
- 건설 실행 취소 단축키 없음(대신 지은 지 하루 안에는 전액 환급).
- 직원 해고 확인 창 없음.
- 영어 등 다른 언어 없음(구조만 준비: `Loc`, 데이터의 `name_en` 필드).
- 게임패드 미지원. 키 설정 변경 없음.
- 도감의 상품·특성 항목에 그림이 없다.
- 지역이 2곳뿐이고, 해안도로는 봇 시뮬레이션으로만 확인했다.
- 메인 메뉴 배경은 정지 그림이다.

## 설계상 의도한 것 (버그 아님)

- 꺼 둔 동안 시간이 흐르지 않는다.
- 운영비를 못 내도 파산하지 않는다(탕감 + 소액 지원금).
- 시설 이동은 무료다.
- 같은 궁합을 여러 번 만들어도 전역 효과는 한 번만 적용된다.
