# ART_GUIDE

## 현재 상태

모든 그림은 `tools/gen_art.py`가 코드로 그린 **1차 자체 제작 픽셀 아트**다. 화풍·광원·외곽선 규칙은 통일돼 있지만, 사람이 손으로 찍은 완성 아트는 아니다. 상업 출시 전에 주요 건물과 캐릭터를 손그림(또는 외부 제작)으로 교체하는 것을 권한다. 교체는 **같은 파일명·같은 크기·같은 기준점**으로 PNG만 바꾸면 된다.

## 방향

- 따뜻하고 편안한 색, 작은 디오라마 같은 화면. 과한 네온·그라데이션·글래스모피즘 금지.
- 건물마다 실루엣과 지붕 색이 달라 한눈에 구분된다. 간판은 글자 대신 9×9 픽셀 아이콘.
- 이모지, 단색 사각형, 원으로 건물·사람을 대신하지 않는다.

## 규격

| 항목 | 값 |
|---|---|
| 타일 | 64×32 px 마름모 (2:1 아이소메트릭) |
| 좌표 | 격자 (x,y) → 화면 ((x−y)·32, (x+y)·16). +x는 오른쪽 아래, +y는 왼쪽 아래 |
| 광원 | 왼쪽 위. +y 면(화면 왼쪽 아래를 향한 벽)이 밝고, +x 면이 어둡고, 윗면이 가장 밝다 |
| 외곽선 | 채움색을 약 60% 어둡게 한 색 1px. 캐릭터·차량은 `#3a3041` 자동 외곽선 |
| 그림자 | 바닥에 반투명 타원(건물), 캐릭터 발밑 16×8 |
| 필터 | nearest. 화면 배율과 카메라 줌은 정수만 |
| 기준 화면 | 1920×1080에서 2배(논리 960×540), 1280×720에서 1배 |

### 건물

- 캔버스 폭 = (w+h)·32, 높이 = 위 여유 + (w+h)·16 + 2. 발자국의 맨 위 꼭짓점 픽셀 위치(ox, oy)를 `assets/sprites/buildings/meta.json`에 기록한다. 게임은 이 값으로 정렬한다.
- 문은 +y 면에 그린다. 게임에서 돌리면(R) 좌우로 뒤집어 +x 면이 정면이 된다. 따라서 **좌우 반전해도 어색하지 않게** 그린다(글자 금지).
- 파일명 `{시설ID}_{단계}.png`, 단계 0/1/2 = 레벨 1·4·8(최대 레벨이 낮은 시설은 비율). 단계가 오르면 화분·차양·깃발·조명·층수 등 **눈에 보이는 변화**가 있어야 한다.
- 평평한 시설(주차장·충전소·정원·놀이터)은 손님이 그 위를 걷는다. 키 큰 소품은 뒤쪽 모서리에만 둔다.

### 캐릭터

- 프레임 16×20, 시트 4열×2행(64×40). 행 0 = 앞모습, 행 1 = 뒷모습. 열 = 서기, 걷기A, 걷기B, 앉기.
- 좌우는 게임이 반전한다. 발이 프레임 아래에서 2px 위에 오게 그린다.
- 유형마다 4가지 색 변형. 유형을 알아볼 단서를 하나씩 둔다(직장인 넥타이, 화물차 기사 모자, 대학생 배낭, 어르신 흰머리·모자, 관광객 챙모자·카메라, 미식가 베레모, 오토바이 헬멧, 고소득 선글라스 등). 아이는 3px 작게.

### 차량

- 캔버스 72×56, 차 중심 바닥이 (36, 34). 길이 방향은 x축.
- `{종류}_{색}_f.png` = +x로 달리는 모습(앞이 보임), `_b` = −x로 달리는 모습(뒤가 보임). y축 방향은 게임이 좌우 반전해 쓴다.
- 종류: car, van, truck, bike, bus, ev, sedan × 색 6.

## 색

기본 팔레트는 `gen_art.py`의 `P` 사전. 잔디 `#7fb86a`, 보행로 `#e2d3b0`, 아스팔트 `#5d6170`, 벽 크림 `#f6e9cf`, 지붕 빨강 `#c8553f`/파랑 `#4a78b8`/초록 `#4e9a6a`/주황 `#e58a3a`. 어두운 쪽은 살짝 보랏빛, 밝은 쪽은 살짝 노랗게.

## 밤낮과 연출

- 밤에는 바닥·건물·사람을 `(0.52, 0.56, 0.84)` 쪽으로 물들이고, 가게 입구와 가로등에 가산 혼합 불빛(`effects/glow.png`)을 켠다.
- 건물 애니메이션: 굴뚝 연기(분식점·우동집·베이커리·사우나), 건설·업그레이드 때 통통 튀는 연출과 반짝이.
- 예정: 카페 김, 분수 물줄기, 자동문, 간판 점등, 계절별 나무 색.

## UI

- 글꼴 Galmuri11(본문 12px)·Galmuri11 Bold·Galmuri9(작은 글씨 10px)·Galmuri14(제목 15px). 안티에일리어싱 없음.
- 크림색 패널 `#f7ecd4` + 갈색 테두리 `#5a4636` 2px, 모서리 직각, 오른쪽 아래 2px 그림자. 강조 주황 `#e9843a`, 긍정 초록 `#4f9d55`, 경고 빨강 `#c9483c`.
- 화면 대부분은 휴게소가 차지한다. 상단 한 줄, 하단 버튼 5개, 왼쪽 목표(접기 가능). 전체 화면을 가리는 창은 특전 선택·등급 상승·전국 평가·회차 달성에만.
