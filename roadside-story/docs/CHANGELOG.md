# CHANGELOG

## 0.1.0 — 2026-11-26 · 수직 슬라이스

첫 플레이 가능 버전.

- Godot 4.4 프로젝트 구성. 시뮬레이션과 화면 분리, 고정 틱, 시드 난수, 데이터 기반 콘텐츠(JSON).
- 월드: 아이소메트릭 타일맵, 카메라 이동·줌, 건설·회전·이동·철거, 보행로, 부지 확장, 배치 미리보기와 불가 사유.
- 손님: 차량 도착·주차·주유, 욕구 기반 시설 선택, 경로 탐색(A*), 줄 서기, 구매, 퇴장. 유형 14종.
- 경제: 실제 판매 기반 매출, 일일 정산, 파산 없음.
- 성장: 시설 레벨 1~10과 외형 3단계, 상품 연구(조합 20), 상품 명성 5단계, 직원 채용·성장(직업 5, 특성 10).
- 발견: 시설 궁합 14종, 통합 도감 8분류, 트로피 10종.
- 특전: 24종 + 조합 8종, 등급 상승 때 3택 1.
- 진행: 등급 7단계, 목표·조언, 전국 평가(5분야, 경쟁 휴게소 9곳), 회차 목표, 무한 경영.
- 다회차: 저장 슬롯 6개, 경영자 명성과 영구 해금, 지역 2곳(시골 국도·해안도로), 도전 2종.
- 이벤트 10종.
- 저장: 자동/수동, 임시 파일 교체 방식, 백업 복구, 버전 필드.
- UI: 상단 정보, 하단 메뉴 5개, 목표, 알림, 발견 배너, 각종 창, 메인 메뉴, 설정.
- 아트·소리: 자체 생성 스프라이트 300여 개, 효과음 18, 배경음악 3, 환경음 3.
- 도구: 자동 테스트, 봇 6종 밸런스 시뮬레이션, 개발자 패널(F1), 화면 캡처 스크립트.
