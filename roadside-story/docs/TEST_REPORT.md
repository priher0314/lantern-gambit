`xvfb-run` + OpenGL 소프트웨어 렌더링, 1920×1080에서 실제 게임을 띄워 캡처로 확인했다.

- 새 게임 직후: 차량 진입 → 주차 → 손님 하차 → 매점 구매 → 매출 숫자 표시
- 봇 45일/60일/200일 경영 화면: 건물 단계별 외형, 줄, 정원 이용, 주차, 밤 조명
- 창: 건설, 연구, 직원, 도감, 시설 정보, 메인 메뉴, 배치 미리보기(범위·불가 사유)

이 과정에서 고친 것: 상단 바 폭, 시설 정보 창이 화면 아래로 넘침(스크롤 추가), 알림이 시설 창과 겹침, 메뉴 배경 잘림, 화면 밖 검은 영역.
