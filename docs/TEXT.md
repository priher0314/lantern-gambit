# 문구·이름 정리 기록

원칙: 짧게, 보이는 그대로, 한 개념은 한 단어. 유물·기술의 **ID와 효과 수치는 바꾸지 않았다**(저장 데이터 호환).
영어는 직역하지 않고 영어권 게임에서 흔히 쓰는 표현으로 따로 붙였다. 현재는 **데이터만 준비**돼 있고, 화면을 영어로 바꾸는 기능은 아직 없다.

## 게임 제목 (미확정 — 승인 후 변경)
**SPIN TILL DAWN으로 확정(2026-11-24).** 제목은 `src/core/data.js`의 `GAME_TITLE` 한 곳만 바꾸면 된다. 부제("달밤 다리의 등지기")와 한글 로고("등불 갬빗")는 삭제했다.

| 후보 | 장점 | 단점 |
|---|---|---|
| SPIN TILL DAWN | 게임이 하는 일(돌린다)과 구조(다섯 밤을 넘긴다)를 그대로 말한다. 발음 쉽고 검색 겹침 적음 | 등불·다리 같은 소재가 드러나지 않음 |
| BRIDGE AFTER DARK | 배경(밤의 다리)이 분명하고 분위기 있음 | 슬롯 게임이라는 게 안 보임. 조금 길다 |
| 밤새 돌려 | 한국어로 입에 붙고 장난스럽다 | 해외 스토어에서 쓸 수 없어 영어 제목이 따로 필요 |
| LAST LANTERN | 짧고 기억하기 쉬움. 패배 문구("등불이 꺼졌다")와 맞물림 | 흔한 조합이라 동명 작품과 겹칠 위험 |
| REEL BRIDGE | 슬롯(reel)과 다리를 한 번에. 말장난(real) | 뜻이 바로 안 와닿을 수 있음 |

추천: **SPIN TILL DAWN** (한국 스토어 표기는 그대로 영문, 필요하면 "밤새 돌려"를 한글 부제로).
