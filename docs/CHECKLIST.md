# 핵심 요구사항 체크리스트

상태: ✅ 구현·검증됨 / 🟡 부분 구현 또는 미검증 / ⬜ 미구현
"검증"의 의미: 🧪 자동 테스트, 🖥️ 브라우저에서 실제 실행(데스크톱 Chrome 기반 미리보기, 모바일 화면 크기 에뮬레이션 포함), 📱 실제 휴대폰(아직 없음)

마지막 갱신: Phase 1 (2026-11-22)
