## Phase 2 2차 — 플레이 피드백 반영
| 피드백 | 상태 | 조치 |
|---|---|---|
| 막힘 적(특히 혼자 남은 탈 방패병)에 대처 불가 | ✅ 🧪🖥️ | 탈 방패에 내구도 2: 정면에서 칠 때마다 깎이고 깨진다(연결·빙고 기술은 한 번에). 남은 방패 수 표시 |

| 3×3 슬롯·빙고 | ✅ 🧪🖥️ | 가운데 줄=공격, 위·아래 가로줄과 대각선 2줄이 맞으면 빙고 보너스 기술 +1 (세로줄은 띠 배열로 정해져 제외) |
| 설명이 길다(금빛·다시 굴리기·몬스터) | ✅ 🖥️ | 카드 문구를 1~2줄로, 큰 글씨·정렬 정리, 화살표 아이콘 제거 |
| "굴리면" 눈 표시 뜻 | ✅ 🖥️ | "↻ 다시 굴리면 1칸 전진/공격력 +2" 글자 꼬리표로 교체 |
| 기술별 연출 | ✅ 🖥️ | 절단=초승달 검기+레인 베기 자국, 동결=회전 눈 결정+얼음 덩어리, 파동=겹물결, 중독=독 방울·거품, 명중 시 문양 스탬프 |
| 등불 수호 → 방어막, +0 표시 | ✅ 🖥️ | 이름 변경, HUD 방어막 게이지(현재/최대), 가득 차면 "이미 가득" 안내 |
| 천둥 북 발동 조건 | ✅ 🖥️ | 발동 시 "◆ 천둥 북 : 처치 → 번개"처럼 조건을 함께 표시 |
| 유물 글자 → 그림 아이콘 | ✅ 🖥️ | 9종 그림 아이콘(HUD·선택·결과 화면) |
| "불씨" 뜻 | ✅ 🖥️ | HUD에서 제거, 슬롯 위에 "퍼펙트 보상: 다음 턴 금빛 릴 ×N"으로 표시 |
| 레버 고급화 | ✅ 🖥️ | 옻칠 뒤판·톱니 허브·금장 팔·등불 유리 구슬·장식 등 |
| "모든 릴에 동결 +1" 뜻 | ✅ | "슬롯에 동결 문양이 더 자주 나온다"로 변경 |
| 타격감 추가 | ✅ 🖥️ | 휘청임·팽창·충격선·처치 슬로모션·더 긴 히트스톱·저음 보강. **체감은 직접 확인 필요** |
