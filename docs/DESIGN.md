# LANTERN GAMBIT — 등불 갬빗 (가제)

> 달밤의 야시장 다리. 축제에서 버려진 물건들이 요괴가 되어 "떠돌이 행렬"을 이루고 다리를 건너온다.
> 플레이어는 **등지기(Lamplighter)** — 점괘 북(슬롯)을 돌려 공격을 얻고, 행렬의 공격을 막고 피하고 되받아친다.

이 문서는 Phase 0 결과물이다. 짧게 유지하고, 실제 구현 상태는 `docs/CHECKLIST.md`에서 관리한다.

## 1. 핵심 재미 정리 (무엇이 이 게임을 재미있게 만드는가)

| # | 재미 | 이 게임에서의 구체적 구현 |
|---|------|---------------------------|
| 1 | 슬롯의 기대감 | 3개의 점괘 북이 순서대로 "쿵" 멈춤. 인접한 두 칸이 같으면 **인연 실**로 묶여 강화 기술, 세 칸이 같으면 **잭팟 궁극기** |
| 2 | 나쁜 결과를 전략으로 극복 | 모든 문양이 쓸모 있다(등불=방어). 발사 **순서**(동결→절단=파쇄)와 **레인 선택**이 결과를 바꾼다 |
| 3 | 배치 읽기 | 3레인 × 6칸. 관통/범위/연쇄가 적 배치에 따라 완전히 다른 결과 |
| 4 | 능동적 방어 | 적 공격 순간 **막기**(넓은 판정, 되치기) vs **회피**(좁은 판정, 적 약점 노출) |
| 5 | 연쇄 시너지 | Phase 1: 파쇄·얼음 파편·감전 연쇄. Phase 3: 이벤트 기반 유물 연쇄 |
| 6 | 몬스터별 공략법 | 우산 도깨비(체력 깎으면 느려짐), 탈 방패병(정면 무효, 회피로 약점), 불씨 초롱(동결로 조준 차단, 퍼펙트로 반사) |
| 7 | 반복 플레이 | 전투 사이 보상 선택(필수) → 릴 구성 자체가 변한다. Phase 4에서 경로·상점·영구 해금 |
| 8 | 타격감 | 히트스톱·피격 플래시·넉백·파티클·충격파·전장 한정 화면 흔들림·합성 효과음 |

### 핵심 규칙 요약
1. **돌리기** → 3릴 결과 = 이번 턴의 "공격 패"
2. **도박 재굴림(턴당 최대 2회)**: 대가(흉조)가 *미리* 공개된다 — "우산 도깨비 1칸 전진", "새 적 등장", "분노 +2" 등. 보상: 재굴림할 때마다 **금빛 릴**이 1개씩 늘어난다(금빛 = 피해+1, 고유 능력+1). 릴 잠금·과열 강화는 사용하지 않는다.
3. **조준**: 공격 패를 고르고 레인을 지정. 미리보기 = 실제 규칙을 상태 복제본에서 실행한 결과 → 항상 일치.
4. **적의 차례**: 앞줄부터 행동. 공격은 줄어드는 고리로 예고.
   - 금빛 고리 = 막을 수 있음(퍼펙트 막기 → **되치기 레인 선택**)
   - 붉은 고리 = 강공격(막기로는 버티기 어려움 → 회피)
5. **퍼펙트** 막기/회피 → **불씨** 획득 → 다음 돌리기에서 금빛 릴로 변환. 조작 실력이 슬롯 결과로 이어진다.

### 방어 행동의 차별화
| | 막기 🛡 | 회피 💨 |
|---|---|---|
| 판정 | 넓음 (퍼펙트 ±75ms / 일반 ±170ms) | 좁음 (±55 / ±125ms) |
| 일반 성공 | 피해 절반 + 작은 반격(1) | 피해 0 + 공격자 **노출**(다음 피격 ×2, 방패 해제) |
| 퍼펙트 | 피해 0 + **되치기**(레인 선택, 관통·방패 무시 3피해) + 불씨 | 피해 0 + 노출 + 불씨 |
| 강공격(붉은) | 퍼펙트여도 절반 피해, 일반은 무효 | 동일하게 회피 가능 |

## 2. 아트 디렉션 3안

### A안 — 「달밤 야시장」 종이·등불 민화풍 ★추천
- **세계관**: 축제 다리 위, 버려진 우산·탈·초롱이 요괴가 되어 행진. 등지기가 등불 지팡이로 다리를 지킨다.
- **팔레트**: 남색 밤(#0b1530) ↔ 따뜻한 등불(#ffb347), 주홍(#e2453c), 비취(#3fcf9f), 한지색(#f3e6c8). 따뜻함/차가움 대비가 강함.
- **실루엣**: 우산(외다리+돔), 탈(큰 타원 얼굴), 초롱(떠 있는 원통) — 형태 자체가 달라 멀리서도 구분.
- **슬롯**: 옻칠 나무 사당 안의 **점괘 북** 3개(한지 띠에 그려진 부적 문양).
- **전장**: 원근감 있는 3갈래 나무 다리 + 결계선(금줄).
- **UI**: 옻칠 버튼 + 금 테두리 + 한지 카드, 둥근 한글 디스플레이 서체.
- **애니메이션**: 관절 분리형 종이 인형 움직임(우산이 접히고, 탈이 들리고, 초롱이 부푼다) → 코드로 구현하기 쉽다.
- **이펙트**: 종이 조각, 먹 튀김, 불씨, 얼음 결정 — 주제와 이펙트가 일치.
- **모바일 가독성**: 매우 높음(어두운 배경 위 발광하는 굵은 외곽선 캐릭터).
- **제작 난이도**: 중. 모든 캐릭터를 Canvas 벡터로 직접 그릴 수 있음.

### B안 — 「천궁 시계탑」 별자리 라인아트
- 천문 기계 속 별자리 짐승. 슬롯은 3겹 아스트롤라베 고리. 얇은 발광선 + 점.
- 팔레트: 심청색 + 금선 + 시안.
- 장점: 이펙트가 우아하고 제작비 낮음. **단점**: 얇은 선이라 모바일에서 적의 크기·위협감이 약하고, 피격 질량감(타격감)이 부족. 몬스터 개성이 약해지기 쉬움.

### C안 — 「유리 온실 포자 정원」 젤리 크리처
- 실험 온실의 해충·포자 생물. 슬롯은 씨앗 분배기. 파스텔 반투명 젤리.
- 장점: 귀엽고 말랑한 스쿼시·스트레치 애니메이션. **단점**: 긴장감·위협감이 낮아 방어/회피의 긴박함과 어울리지 않음. 파스텔 배경에서 경고색 대비가 약함.

### 추천: A안
1. **게임플레이 일치**: "점괘 북을 돌려 운을 시험한다(갬빗)" + "다리를 지킨다(3레인)" + "공격을 받아친다"가 하나의 세계관으로 묶인다.
2. **예고 가독성**: 밤 배경에서 금빛(막기)·붉은빛(회피) 고리가 확실히 튄다.
3. **타격감**: 종이가 찢기고 탈이 깨지는 물리적 파괴 표현이 가능.
4. **제작 현실성**: 외부 이미지 생성 도구 없이 Claude가 코드로 끝까지 제작·수정 가능.

## 3. 기술 구조

- **순수 HTML + ES 모듈 + Canvas 2D + Web Audio**. 빌드 도구 없음 → 정적 호스팅(GitHub Pages/Netlify)에 그대로 업로드하면 HTTPS 링크로 공유 가능. 추후 PWA/Capacitor 포장 가능.
- **규칙(core)과 연출(render/game)을 완전히 분리**. 규칙 엔진은 결과를 "이벤트 목록"으로 돌려주고, 연출은 그 목록을 재생만 한다.

```
src/core/rng.js      시드 난수 (상태 안에 저장 → 복제 시 함께 복제)
src/core/data.js     문양·기술·적·전투·보상 데이터
src/core/slot.js     릴 결과 → 공격 패(연결/잭팟) 판정
src/core/battle.js   턴 진행, 공격 판정, 적 AI/예고, 반응(막기·회피·되치기), 목표
src/core/timing.js   타이밍 판정 창
src/core/run.js      한 판(런) 진행, 보상
src/audio/audio.js   합성 효과음 + 절차적 BGM
src/render/art.js    캐릭터·문양 벡터 아트
src/render/fx.js     파티클, 흔들림, 히트스톱, 플래시
src/render/scene.js  배경, 전장, 슬롯, HUD 그리기
src/game.js          입력, 이벤트 재생, 흐름 제어
src/ui/overlay.js    타이틀·보상·결과·설정 화면 (HTML)
tests/               node:test 규칙 테스트 (미리보기=실제, 결정성, 중복 처치 방지 등)
```

- **미리보기 일치 보장**: `previewShot()`은 상태를 `structuredClone`해서 실제 `fireShot()`을 실행한다. 별도의 "예측 코드"가 없으므로 어긋날 수 없다.
- **연쇄 안전장치**: 처치된 적은 다시 피해/처치되지 않음(`alive` 검사), 파편 연쇄 깊이 제한, 한 기술 안에서 같은 적에게 전격 중복 금지.
- **화면 흔들림은 전장 레이어에만** 적용. HUD·슬롯·버튼은 절대 움직이지 않는다.
- **입력**: 반응 단계에서 첫 입력만 인정(이중 입력 차단), 연출 중 행동 입력 차단. 터치는 "레인 한 번 = 미리보기, 한 번 더 = 발사", 마우스는 호버 미리보기 + 클릭 발사.
- **화면**: 세로(portrait) 고정 논리 폭 540, 높이는 기기 비율에 맞춰 880~1200 가변 → 한 화면에서 스크롤 없이 플레이.
